とりあえず脱出を試みましょう。

●詳細説明
・バージョンは1.8.1または1.8.3です。
・クリア推定時間は１時間~2時間半程度です。
・一部コマンドが使用できないため、1.8.xより前のバージョンだと絶対にプレイできません。
・エンディングは1つです。
・感想などやアドバイスなどがございましたらフォーラムまたは私のツイッター(@gol559)まで報告をお願いします。

○必須設定
・難易度：ノーマル
・アドベンチャーモード
・ＰＶＰオフ(マルチの場合)
・そのほかの設定は自動で行われます。
・マルチプレイの場合はserver.propatiesにspawn-protection=0とenable-command-brock=trueとspawn-animals=trueを追記してください。

○推奨設定(任意でＯＫです)
・マインクラフトのＢＧＭオフ
・明るさ設定50～100程度
・プレイ人数は1～4人程度
・グラフィックス:描画優先
・パーティクルの表示:すべて
